# Quantum Computing Fall Fest 2026 — Static site

This is a lightweight static website for Quantum Computing Fall Fest 2026.

Contents:
- index.html — main site
- styles.css — styling
- script.js — small JS for tabs, nav, registration mailto, ICS download

Quick start (publish to GitHub Pages):
1. Create a new repository (e.g. `qc-fall-fest-2026`) and push these files to the default branch.
2. In the repo Settings → Pages, select the branch and folder (root) to publish.
3. The site will be available at `https://<owner>.github.io/<repo>/` (or at the repo's custom domain if configured).

Customizations:
- Change dates shown in the header and the schedule in `index.html`.
- Change registration target email in `script.js` (`vivekiniitm@afucommunity.com`) and in the page copy.
- Replace speaker entries and photos in the Speakers section.
- If you want a proper registration backend (database + payment), I can add a server or integrate Eventbrite/Google Forms.
